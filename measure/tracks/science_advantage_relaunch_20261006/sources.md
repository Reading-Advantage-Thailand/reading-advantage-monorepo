# Science graph sources (Phase 0, 2026-10-06)

Indicator codes below are the official ones from the Basic Education Core Curriculum B.E. 2551, science and technology learning area, revised B.E. 2560. ## Scope note for D4

Science Advantage covers strands 1 to 3 (Science of Life, Physical Science, Earth and Space Science): 20 P3 indicators and 16 P4 indicators. Strand 4 (Technology, ว 4.2 computing science) stays out of the workbook and the graph in 2027; a school's computing class covers it. Science process skills (observe, measure, classify, predict, infer, communicate, control variables, interpret data) become `skill` nodes without an indicator code; the ว 1 to ว 3 indicators carry `aligned_to_standard` edges to `standard` nodes.

## Node ID pattern (SPECIFICATION.md §3.6)

`science.th2560.standard.v1-2.p3-1` for the standard node of ว 1.2 ป.3/1 (strand.standard, grade-index); `science.th2560.skill.p3.<topic-kebab>` for the learnable skills under it; `science.process.<skill-kebab>` for process skills; `science.vocab.<word-kebab>` for bilingual vocabulary. Domain `science.th2560`. NGSS codes go in `alignmentRefs`. The graphs session reads the v0 node ID list once against the English key conventions (agreed 2026-10-06).
