# Test Strategy: APK Incomplete Sentence Action W1

## Principal risks

- Flattening two distinctive mechanics into the existing sentence collector.
- Ambiguous duplicate words, unreachable correct targets, or state transitions that advance twice.
- Canvas animation diverging from pure tested rules.
- Touch controls that exist visually but cannot complete a real round.
- Public catalog status changing before the deep link launches a real cartridge.
- Prematurely trusting these QC-only game IDs at the authoritative completion boundary.

## Red-first layers

1. **Family contracts:** deterministic target-action rounds, stable duplicate IDs, adjacent-step graphs, reachability, projection, legal transitions, and counterexamples.
2. **Cartridge contracts:** strict nonempty sentence preflight, blank rejection, public manifest/capability/slot requirements, exact result parsing, and completion once.
3. **Edition contracts:** both packs provide identical required semantic slots, valid provenance, and safe audience tuning without scene branches.
4. **Catalog contracts:** exact loader/manifest parity across five public IDs and retained rejection of retired foundation IDs.
5. **QC component tests:** discovery, public deep-link selection, public result identity, reset, and retired-label absence.
6. **Host tests:** Reading Secondary Epic and Primary Chibi load both new sentence cartridges through literal package loaders and unchanged pair arrays.
7. **Browser acceptance:** real keyboard/pointer and touch actions, both editions, one-canvas lifecycle, completion result, and 390x844 no-overflow checks.
8. **Cutover guards:** both cards target valid QC deep links; both remain excluded from authoritative completion until production persistence is wired.

## Required counterexamples

- Empty input, whitespace term, whitespace translation, and a term that tokenizes to no words.
- Repeated token text with distinct stable IDs.
- Unknown, repeated, dead, or nonadjacent target/node selection.
- Wrong choice advancing progress or correct choice incrementing more than once.
- Ziggurat graph without a reachable correct next node.
- Loader key whose manifest ID differs.
- Query string containing an unknown or retired cartridge ID.
- Client completion payload attempting to supply XP, identity, or tenancy.

## Acceptance commands

- Game-cartridges lint, check-types, test/coverage, and build.

- Focused Advantage Games QC Jest and complete APK Playwright suite.
- Focused Reading and Primary host tests.
- Advantage Games check-types and production build.
- Targeted graph update/search/caller checks.
- Measure doctor with unrelated concurrent-track failures recorded explicitly.
