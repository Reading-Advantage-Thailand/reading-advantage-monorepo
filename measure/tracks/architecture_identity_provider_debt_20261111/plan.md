## Rules for this plan

- Markers: `[ ]` pending, `[~]` in progress, `[x]` done, and `[b] … deferred:<owner>` at a human gate. A task in a later phase starts only after the phase heading carries its checkpoint.
- An `[x]` note names the commit and the evidence class: automated, person-checked, or owner-passed.
- Tests first. The Red test fails at HEAD for the stated reason. The Green change is the minimum.
- Red runs on the MiniMax model family. Green runs on the DeepSeek model family. Green does not use the Anthropic family.
- Stage named paths only. Never run `git add -A` or `git add .`. Commit with `git commit -m <msg> -- <paths>`.
- No push, no deploy, no amend, no `--no-verify`, no `git reset`, `checkout`, `restore`, `revert`, or `stash`, and no `git worktree add`.
- Heavy steps run through `HEAVY_PRIORITY=p2 HEAVY_RUN_TIMEOUT_S=1800 HEAVY_MIN_AVAIL_MB=1500 HEAVY_PREFLIGHT_WAIT_S=3600 bash /home/daniebo/Desktop/advantage-pr/scripts/jobs/heavy-run.sh -c '<command>'`. - Every named-file vitest command carries `--maxWorkers=1` and `CI=true`. Package suites, type checks, lint, the pin refresh, `pnpm architecture:check`, and `build-graph update` run through heavy-run.
- No new hash, checksum, or manifest (`AGENTS.md`, Hashing and Provenance Policy). The pin refresh and the baseline update write only the files that they already write.
- Green does not change `packages/architecture-enforcement/src` production code, `ownership-map.v1.json`, `ownership-map.v2.json`, the ratchet tests, or `measure/archive/`. A needed rule change stops the task and goes to the orchestrator (spec D-3, OQ-1).
- A task that finds a new finding stops and reports (spec FR-8).
- The Red commit changes the test tree of `packages/architecture-enforcement`, and each Green commit changes analyzed files. The full check can stay red between those commits and the refresh of task N.3. No push happens before the phase check.
- Commit headers are 100 characters or less and use a lower-case subject. Each header carries `(track_id: architecture_identity_provider_debt_20261111)`. The suffix uses 57 characters, so the type and the subject use 43 characters or less.
- Paths start at the monorepo root. At the end of a phase, run the phase check and append `[checkpoint: <sha>]` to the phase heading.
