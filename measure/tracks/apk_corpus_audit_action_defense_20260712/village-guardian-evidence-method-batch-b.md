## Negative-fixture policy

Fixtures are refutations, never claims. A valid hash does not rescue an anchor that semantically overstates behavior. A tree object is not a file citation. A plausible persistence mechanism must be present in the cited source, not merely expected. Responsive conclusions cannot be selected by keywords, generic templates, or analogy.
