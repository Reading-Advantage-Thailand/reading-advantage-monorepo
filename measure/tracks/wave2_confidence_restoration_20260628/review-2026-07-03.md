## 3. Code Quality Observations

- **Red-green discipline is strong:** each fix commit is preceded by a `test(...): ... red` commit and the plan records red evidence and green verification commands.
- **Diagnostic labels are present:** counts use explicit labels (`Required migration behind count`, `Wrongly-skipped canonical lesson count`, `Live-default prod-smoke file count`, etc.) rather than bare assertions.
- **Honest ratchets:** the observability guard pins `CONSOLE_ERROR_BASELINE = 621` and fails on *new* `console.error` call sites without claiming the debt is paid off.
- **Deferred ownership is explicit:** `internal-sdk` quarantine, full `AIClient` adoption, and the `console.error` sweep are all marked `[b] deferred:wave6`.
- **Test utilities are isolated:** all harnesses live in `testing/` subpaths and are deliberately omitted from package `exports`, keeping them out of shipped API surfaces.
