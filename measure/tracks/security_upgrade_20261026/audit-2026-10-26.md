| CVE | Severity | Affects 22.x | Title |
| --- | --- | --- | --- |
| CVE-2026-111497 | high | yes | Node.js Brotli decoder out-of-bounds write permits remote code execution |
| CVE-2026-105482 | high | yes | dns.resolve truncates names containing NUL char |
| CVE-2026-106069 | high | yes | TLS certificate hostname bypass when the host loosely resolves to an IP address |
| CVE-2026-105481 | medium | yes | Keep-alive socket process a response that was written before the request was sent |
| CVE-2026-106072 | medium | yes | Improper certificate validation for non-canonical IPv4 hostnames allows DNS SANs to authenticate IP endpoints |
| CVE-2026-106074 | medium | yes | crypto.randomUUID() and randomInt() entropy caches are saved into user-land startup snapshots and SEAs |
| CVE-2026-106073 | low | yes | Permission Model bypass with fs.realpathSync |

The release also updates the dependency `c-ares`, `ca-cert`, `OpenSSL`, `SQLite` and `Undici` on the 22.x line.

### 7.2 The base image tag

The tag `node:22-alpine` follows the 22.x line. A rebuild of the image pulls 22.23.4 and the fix. The tag needs no change.

One Dockerfile breaks the pattern. `apps/reading-advantage/Dockerfile` starts `FROM node:20.18`. Node 20 reached end of life, so the image receives no October 2026 fix. That app needs a separate decision from Daniel's team, because the change moves it to a new runtime line.

## 10. Findings for the track

1. The `next` bump to 16.4.1 is a MINOR bump. The `overrides` block in `pnpm-workspace.yaml` holds every resolved `next`, so one override change covers all fourteen workspace units.
2. The `react` and `react-dom` bump to 19.2.9 is a PATCH bump inside the 19.2 line. The `overrides` block covers both.
3. The `sharp` bump to 0.35.5 is a MINOR bump. The catalog entry `sharp: ^0.34.5` does not allow it, so the catalog entry changes.
4. The `vite` bump to 8.1.6 is a PATCH bump. The `overrides` block pins `vite: 8.1.0`, so the override changes.
5. The `handlebars` bump to 4.7.10 is a PATCH bump. The `apps/reading-advantage` range `^4.7.8` and the `packages/domain` range `^4.7.9` allow it. The lockfile refresh alone fixes the version.
6. The `@sentry/nextjs` bump to 10.75.2 is a MINOR bump. The `apps/science-advantage` range `^10.0.0` allows it. The lockfile refresh alone fixes the version.
7. The `axios` bump to 1.20.0 is a MINOR bump. The catalog entry `axios: ^1.7.7` allows it. The lockfile refresh alone fixes the version.
8. The `nanoid` bump to 5.1.16 is a PATCH bump. The catalog entry `nanoid: ^5.1.11` allows it. The lockfile refresh alone fixes the version.
9. The `postcss` bump to 8.5.18 is a PATCH bump on the 8.5 line and a MINOR bump on the 8.4 line. The catalog entry `postcss: ^8.5.15` allows it. The lockfile refresh alone fixes the version.
10. The `undici` bump to 7.30.1 is a MINOR bump. The package runs in dev only, through `jsdom`. The lockfile refresh alone fixes the version.
11. The transitive packages need no manifest change. A lockfile refresh resolves them: `brace-expansion`, `browserslist`, `compression`, `extract-zip`, `fast-uri`, `fast-xml-parser`, `follow-redirects`, `image-size`, `ip-address`, `js-yaml`, `source-map-js`, `url-regex`, `@fastify/busboy`, `@grpc/grpc-js`, `@opentelemetry/exporter-prometheus`, `@opentelemetry/sdk-node`, `@xmldom/xmldom`.
12. The `node:22-alpine` tag needs no change. A rebuild pulls Node 22.23.4.
13. The `apps/reading-advantage/Dockerfile` base image `node:20.18` needs a decision from Daniel's team. The change moves the app to another runtime line.
14. A version-guard test must read `pnpm-lock.yaml` and fail while any locked version sits below the fixed version of a critical or high advisory.
