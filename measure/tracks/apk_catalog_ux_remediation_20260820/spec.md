# Specification: APK Catalog UX Remediation

Repair documented catalog APK defects from
`measure/audit-reports/advantage-games-ux-wiring_20260819/`.

## Goal

A student can open a catalog card, sign in when needed, play a winnable game,
leave through a working Exit path, and see honest covers, controls, and results.
