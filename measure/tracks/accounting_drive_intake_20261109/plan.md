## Rules for this plan

- Markers: `[ ]` pending, `[~]` in progress, `[x]` done. An `[x]` note names the commit and the evidence class: automated, person-checked, or owner-passed.
- Each task follows `measure/workflow.md`: tests first, then code, then one commit with `(track_id: accounting_drive_intake_20261109)`. The header is 100 characters or less.
- Stage named paths only. Other sessions commit on master. Never run `git add -A` or `git add .`.
- Every Green task that writes code has a Red task before it. A Red task holds the test file only.
- Tests use fakes only. No real finance document and no real amount enters git, a test, a log, or a non-Vertex model route (never the Aliyun plan, never OpenRouter).
- No new hash field, no checksum column, and no manifest (AGENTS.md hashing policy).
- **Start gate.** The build code starts after 2026-11-20. An earlier start uses only a slot that Storytime does not need. Before 2026-11-20 this track holds spec and plan work only. The PM first load of 2026-11-10 and the PM structure report of 2026-11-11 are PM tasks in Phase 5. They are not build work and they do not wait for the gate.
- Every new Drizzle table is classified in `packages/domain/src/tenant-registry.ts`. Default classification is `EXEMPT`.
- Business logic lives in `packages/backend/src/modules/accounting`. Route handlers stay thin. Provider SDKs stay behind adapters.
- The intake folder is Daniel's existing Drive folder `Accounting`. The poll reads its top level and, from 2027, the subfolder of the current year. The poll never reads the `2024` and `2025` folders. The folder id comes from `ACCOUNTING_DRIVE_FOLDER_ID`; no id enters git.
- A deferred task is marked `deferred:pm` or `deferred:daniel`. It carries no code in this track.

The action columns are `text` with check constraints, so widen or add a check with `DROP CONSTRAINT` and `ADD CONSTRAINT` in one migration. The close audit trail is a new table, so the submission audit table needs no change.
- The durable job tables live in the main product database (`packages/db/src/schema/jobs.ts:44`). The accounting poll does not reuse them. It uses the lease row of FR-6 (open item Q12).
- Red-phase commits hold only the test file and the Measure doc edits. Check `git status --short` before every commit (lessons-learned, `ci_typecheck_alignment_20260603`).
- The Vertex path uses Application Default Credentials (PM-3). No `VERTEX_CLIENT_EMAIL` and no `VERTEX_PRIVATE_KEY` is set for this track.
