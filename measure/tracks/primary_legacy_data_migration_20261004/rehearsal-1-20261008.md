## Defects found and fixed

1. **Times moved 8 hours early.** postgres.js read the legacy `timestamp(3)` columns in the process
   time zone (this machine: UTC+8), so every moved time (XP, reading logs, card due dates, license
   expiry, class code expiry) was 8 hours early. Found by the new student sample check. Fix: the
   legacy connection reads `timestamp` as UTC (`LEGACY_UTC_TIMESTAMP`, integration 7bb6b1065).
   `primary_etl_20261007` keeps the shifted times; rehearsal 1 replaces it.
2. **Question order arbitrary.** The questions of an article share one `createdAt`; the ETL numbered
   them by `ctid`. Workbooks' verify found 11 packages with a different order (59 MCQ, 2 SAQ rows).
   Fix: order by `createdAt`, then the cuid id (`QUESTION_ORDER_SQL`, 7bb6b1065).

Not a defect: locally, `pnpm --filter @reading-advantage/db doctor --check` runs the built-in
`pnpm doctor`, because `~/.local/bin/pnpm` is a shim for `npx -y pnpm`. Cloud Build uses corepack
pnpm 11.8.0, and its `doctor-check` passed (2026-09-24). Locally, use `pnpm ... run doctor`.

   picture password, so no migrated student can sign in until the teacher presses "Give picture
