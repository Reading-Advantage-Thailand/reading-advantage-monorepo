## APK cutover / host-proof (2026-08-03)
- **reasonix for bulk; Grok for verification only.** AGENTS.md: bulk mechanical work is `reasonix run --dir <REPO> --permission-mode acceptEdits -p "…"`. In-loop bulk formals/SCRATCH/dual-host ports burns weekly token budget without extra correctness. High-risk host clients, Measure claims, and commits stay in-loop.
- **Multi-title host client must accept any `*_HOST_PROOF_ACTION`.** Filtering only `DRAGON_FLIGHT_HOST_PROOF_ACTION` drops magic-defense/castle-defense/etc. diagnostics so checkpoints never form. Client tests must inject non-DF codes with `gameType=…`; domain multi-title alone is not the host bridge.
- **Option-1 terminal graph needs one fact table + agreement checker.** Field-by-field formals drift (stale c3, zero-deletion language, SHA mismatch). Prefer `apk_option1_terminal_truth_*.json` + whole-file regen of formals/dispositions/authority; never agent self-sign track-complete.
- **Criterion 3 is exact retirement, not empty candidates.** Task-6 empty-delete lists while live callers exist is incomplete; either rewire→delete (option 1) or explicit deferred/blocked with disclosures—not zero-deletion as complete.
- **Primary Vitest dynamic imports of package subpaths need dist or source aliases.** `vi.mock({ virtual: true })` does not satisfy Vite import analysis for `@reading-advantage/game-cartridges/legacy-*-host-proof`.

## Workbook port (2026-08-04)
- **A round-trip test proves nothing beyond its fixture's fields.** `origins-2-a0` carries 25 of the ~35 fields `draftLessonSchema` accepts, so "keeps every fixture field intact" passed while `writing_practice_url` was destroyed on every save. Pin a maximal fixture to the schema with `Object.keys(schema.shape)` so a new field without a mapping fails the suite. Doing so immediately exposed a second defect (structured article images emitted into both editor fields, duplicating the URL each save/load cycle).
- **Classify new tables in `tenant-registry.ts` in the same commit as the migration.** Migration `0048` shipped unclassified and left the FR-6 tenant-coverage gate red for a day. Tables scoped by a non-`schoolId` key are REFERENTIAL (TenantDB fails closed) + one documented `unscoped(reason)` at the adapter boundary — not EXEMPT, which means genuinely global.
- **Plan status drifts silently when work lands out of order.** This track sat at `status: "new"` with every task `[ ]` through nine commits, so `status`/`review` reported fiction. Reconcile against the tree and record the SHA per task; use `[~]` with the gap stated inline rather than checking a task that only partly landed.
- **Test files can be committed without ever running.** Four editor suites were co-located under `components/` while the vitest `include` globs covered only `app/` and `lib/`, and imported `../X` instead of `./X`. Both wrong, both invisible — a green suite count is not evidence a given file ran.
- **Adding an optional field to a strict schema carrier requires auditing every rebuild site.** `settings` on `workbookSourceRecordSchema` was dropped by `updateWorkbookDraft`'s wholesale record rebuild, so content saves silently erased it (found by `claude -p` review, not tests). Every site that reconstructs the carrier must spread the new field; add a preservation regression test per site.
- **A mocked hook return in view tests silently lacks new hook fields.** Extending `useDraftLessonEditor` broke the settings flow only in the view because `mockReturnValue` predated the new fields — `undefined` revision + missing `applySettingsSave` caused phantom failures. Centralize the mock in a `makeHookReturn(overrides)` factory so new fields fail typecheck instead of tests.
- **Teacher-manual adapter reverses the importer, not the generator wishlist.** `toTeacherManualLesson` (bite 1, 2026-08-04) maps normalized→legacy with the importer's exact empty/absent rules, and the maximal fixture is pinned to `workbookNormalizedContentSchema` while the round trip goes back through `importLegacyWorkbook` — so a new carrier without a legacy field (e.g. `writingPracticeUrl`) fails the "drops no-counterpart fields" test instead of silently vanishing. Article images carrying only a canonical `key` (no `legacyUrl`) map to an empty legacy `url`; bite 2 must resolve keys through an asset service before rendering.
- **Bite-2 generator port: legacy escapeHtml duplication is pervasive, and one call site is intentionally raw.** All six generator modules carry their own `escapeHtml` copy (now collapsed to the shared `theme.js`). `t.preface.welcome(seriesName, seriesLevel)` interpolates series metadata **unescaped** (it builds `<strong>…</strong>`), so the title-page-only escaping test had to scope assertions to the title block. `generateEndMatter` accepts `_data` and ignores it; `buildPeriodPlan`/`renderPeriodPlan` carry unused `_theme`/`_lessonIndex`. Period grouping for assertions must follow the step↔period map (step 8's short-answer lives in period 3, step 11's writing prompt in period 4).
- **Print contract (bite 3): the parent never touches `contentWindow.print()` on a sandboxed frame.** Without `allow-same-origin`, that call throws a cross-origin SecurityError; instead the parent posts `iframe.contentWindow.postMessage("workbook:print", "*")` and the generated document owns the `window.print()` listener. Frames keep `allow-scripts allow-modals` and NO `allow-same-origin`.
- **`getByLabelText` includes `aria-hidden` text; `getByRole` does not.** testing-library's label matcher uses raw label `textContent`, so wrapping a visible-but-decorative id in `aria-hidden="true"` still leaks it into `getByLabelText`. Assert accessible names with `getByRole("checkbox", { name })`, which runs the real accname algorithm.
- **JSON editor fields need raw local text, not a fully controlled `value={JSON.stringify(...)}`.** Intermediate invalid fragments revert (users can't type). Keep raw text in local state, propagate only successful parses, and re-sync on upstream **identity** change via the render-phase adjust pattern — never via an effect on the serialized string, which changes on every parent render and clobbers in-flight typing.

## Recurring Gotchas (condensed)
- FR-2 greps need runtime call shapes, not only imports (primary drizzle). Drizzle migrator skips non-monotonic `when` stamps. Audit log DELETE needs `DIRECT_DATABASE_URL` + advisory lock. Next.js 16 `proxy.ts` is nodejs (no edge `runtime`).
- Shared checkout: the git index is shared state across concurrent agents—commit with `git commit -- <pathspec>` only, never bare `git add`+`git commit` (a sibling's staged renames got swept into a business-ops commit, 2026-08-03). Committed evidence dirs under `measure/tracks/` are read-only to automation and sibling agents; path-sync must never cross track boundaries (frozen R1 v2 snapshot was rewritten twice).
- Transaction-mode pooling: `prepare: false`, split DATABASE_URL/DIRECT_DATABASE_URL, entrypoint guard for CLI db scripts.
- `FOR UPDATE SKIP LOCKED` job queues work without Redis; adversarial-test URL parsers and DLQ boundaries.
- Never bend production code for structural string assertions in tests. Source-scan guards need counterexample fixtures. Ratchet large deferred sweeps; don't zero.
