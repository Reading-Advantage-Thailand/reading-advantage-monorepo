| --- | --- |
| `tabs` | `/student/read` with the tab sign "Articles (selected) \| Stories". The toolbar keeps four tabs. |

| `shelf-empty` | A search with no result: the short note and "Clear the filters". |
| `story` | The story page: cover, badges, summary, Chapters sign (selected), the chapter list with "Done" marks. |
| `characters` | The same page with the Characters sign selected. |
| `chapter` | The chapter page: desk card, translation signs, picture, read-along text, translation line, previous and next, player. Word list and questions panel in the side column. |
| `q-mcq` | MCQ: one question, 4 options, timer, back and next. |
| `q-result` | MCQ result: score, XP, the note that a retake gives no more XP. |
| `q-saq` | SAQ: answer box, AI feedback, score, submit. |
| `q-laq` | LAQ: the character counter, the "write a longer answer" note, the feedback tries left. |
