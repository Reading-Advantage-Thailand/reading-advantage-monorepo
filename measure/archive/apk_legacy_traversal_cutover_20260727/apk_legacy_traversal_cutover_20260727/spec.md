# Specification: APK Legacy Traversal Rebuild and Cutover

## Scope

Rebuild and vertically cut over Dragon Rider, Spellweaver's Run, Shadow Gate Dungeon, Labyrinth of the Goblin King, and Griffin Rider's Escape.

## Requirements and acceptance

- Use accepted source evidence to preserve each title's distinct traversal/learning loop, not legacy renderer details.
- Require separate semantic adoption and selected-output proof for each title.
- Require an accepted suitability dossier for each role that distinguishes semantic
  intent, physical descriptor/animation behavior, and reuse/ingest/block outcome.
- Execute per-title Advantage Games, Reading, Primary, and exact-retirement proof; stop affected work on a missing capability, mapping, or host gate.
- Acceptance requires reviewed, owner-approved evidence for all five titles without app-local asset copies or whole-pack default delivery.
