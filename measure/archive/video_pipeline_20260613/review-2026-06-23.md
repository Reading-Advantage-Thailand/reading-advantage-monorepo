## Code quality observations

- **Strengths:**
  - TDD wiring tests were committed before route implementation (Phase 5 and Phase 6 Red tests).
  - Scene editor is pure and immutable.
  - The script prompt is clear and constrains output to a JSON array.

- **Concerns:**
  - `script-schema.ts` rolls a custom validator instead of using Zod, which is inconsistent with the rest of the monorepo and lacks rich error messages.
  - `generate-script` route uses an inline `as { app: string; topic: string }` cast and parses LLM output with `JSON.parse` before schema validation — malformed LLM output can throw unhandled exceptions.
  - Error responses return generic 500s without structured diagnostics.
  - The route imports `createAIClient` from `@/lib/ai` (app-local) rather than the shared `packages/ai` adapter; this duplicates AI-client configuration.

## Risks or blockers

1. **Untracked track:** No prior spec/plan meant no acceptance criteria were agreed before implementation. The retroactive spec may miss product intent.
2. **Custom validation vs Zod:** Increases maintenance cost and inconsistency with `@reading-advantage/domain` / API route conventions.
3. **No build verification:** `apps/marketing` build, lint, and check-types have not been run; Next.js 16 + TypeScript strict may surface issues.
4. **LLM reliability:** JSON parsing errors from the model are not gracefully handled.
5. **Shared-package divergence:** App-local AI client may drift from the central `packages/ai` interface.

## Recommended next actions

1. Replace `script-schema.ts` custom validator with Zod and add edge-case tests (empty array, too many scenes, missing fields).
2. Refactor `generate-script/route.ts` to use Zod for body parsing and wrap `JSON.parse` in a structured error handler.
3. Run `pnpm turbo run lint test check-types build --filter=marketing` and fix all issues.
4. Evaluate whether `apps/marketing/app/lib/ai` should be replaced with `@reading-advantage/ai` to avoid duplicate AI-client configuration.
5. Add unit tests for `scene-editor.ts` and `deduplicateTopics` helper.
6. Add a project-save integration test and verify the `video_projects` table is queried/updated correctly.
