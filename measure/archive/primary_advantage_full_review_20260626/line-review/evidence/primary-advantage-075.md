### LR-primary-advantage-075-001 — `cefr-level-evaluation-prompts.json` copies "secondary students" wording into a primary-targeted app across all 6 CEFR level entries

- Severity: High
- Fork-divergence category: Fork-specific regression
- File: `apps/primary-advantage/data/cefr-level-evaluation-prompts.json:4,8,12,16,20,24`
- Evidence: Every CEFR level entry (A1 line 4, A2 line 8, B1 line 12, B2 line 16, C1 line 20, C2 line 24) in this primary-advantage prompt set tells the model to flag content that is "inappropriate content for secondary students" (A1 line 4), "inappropriate for secondary students" (A2 line 8, B1 line 12, B2 line 16, C1 line 20, C2 line 24), and to automatically assign the worst score to "ANY INAPPROPRIATE CONTENT" for secondary students (B1 line 12). This is a primary-school product for ages 7-12 — the rubric, as written, is calibrating a "1 = Poor" tier around content that would be unsuitable for 12-18 year olds, not for 7-12 year olds. The same file exists at `apps/reading-advantage/data/cefr-level-evaluation-prompts.json` (grep over `apps/reading-advantage` confirms it is the source of truth used by `apps/reading-advantage/server/utils/generators/evaluate-rating-generator.ts`), so the copy in primary-advantage is an unrevised copy of the secondary-targeted rubric.
- Impact: When primary-advantage routes an AI evaluation through this prompt (or a future contributor wires it in), the model will mark age-appropriate primary content (e.g., topics about "Friendship", "Family", "Recess", "Pet Care" that this app's own `genres.json` lists as primary-level nonfiction) as "inappropriate for secondary students" and assign the worst score tier. This would systematically downgrade content the app is designed to teach. Even though the file is currently an orphan in primary-advantage (see LR-primary-advantage-075-003), a future re-wiring would silently inherit a secondary-school calibration error. A 7-12 year old who writes about "My favorite pet" would be penalized because the rubric is tuned for "secondary students".
- Recommendation: In a separate authorized content-remediation track, rewrite the rubric to reference "primary students" (or the age band "7-12") and recalibrate the "inappropriate content" thresholds to age-appropriate definitions (e.g., explicit violence, adult themes). The fork should also delete this orphan file in favor of the children-specific `data/new-level-evaluation-prompts.json`, which uses a star-rating (1-5) and `cefr_level` schema with `+/-` modifiers and explicitly references "children's literacy and language assessment for elementary students (grades 3-6)" — that file is the correct primary-advantage rubric. No source edit performed in this review-only track.

### LR-primary-advantage-075-011 — `data/level-test.json` has distractor options with grammar errors that exceed the target CEFR level or are syntactically broken, undermining the placement test's diagnostic value for primary students

- Severity: High
- Fork-divergence category: Primary-student adaptation risk
- File: `apps/primary-advantage/data/level-test.json:184,191` (with secondary references at 137, 144, 152, 160, 174, 198, 207, 227, 237, 245, 269)
- Evidence: Multiple distractor options in the level-test questions contain errors that go beyond "the wrong grammatical form" and into "ungrammatical or broken English", which makes them indistinguishable from the correct answer in a way that fails the placement test's diagnostic purpose. The most concerning cases:
  - Line 184 (B1, Q3, option C): `"Is cold in here, indeed."` — missing the subject pronoun "It", making the sentence syntactically broken in a way a 9-11 year old B1 learner is not expected to parse. The grammatical error is not a teaching cue; it is a non-sentence.
  - Line 191 (B1, Q4, option C): `"I haven't reading about it yet."` — uses the present perfect continuous, which exceeds B1 in the level descriptors on line 13 (`"B1: A range of common words with some less familiar vocabulary. Sentences of moderate length (8-10 words on average) with some variety. A range of tenses and some complex structures."`) and is the C1+ form. A B1 student would not be expected to spot that this distractor is "too advanced" rather than "wrong".
  - Line 174 (B1, Q1, option B): `"It might be where you left."` — incomplete; the relative clause is missing a direct object ("It might be where you left it."). An A1-level student could plausibly read this as correct.
  - Line 269 (B2, Q6, option C): `"I getting stressed easily."` — three errors compressed into a single five-word distractor; this is not a calibration of "wrong" but a jumble that the B2 learner would rule out only because the surface form is so broken.
  - Line 198 (B1, Q4, option B): `"It's quite complicated program."` — missing article "a", which is the B1-level error being tested in the correct A option, but the A option is `"I think it's a great idea for our environment."` which is a different error pattern. The test mixes an article error (B1) with a content error (B1 is also about "recycling program"), making the test ambiguous.
  - Line 152 (A2, Q5, option C): `"Zoos is fun."` — subject-verb agreement error appropriate for A2, but `"Zoos"` as a plural subject is unusual for an A2 student; the more common A2 distractor would be `"Zoo is fun."`.
  - Line 207 (B1, Q6, option C): `"I like learning language."` — missing article "a" before "language" — a B1-level error, but the A option `"To make friends and to watch movies without subtitles."` is an A1-style infinitival response that the B1 test may confuse.
  - Line 237 (B2, Q2, option C): `"Museums are very expenses."` — uses noun "expenses" instead of adjective "expensive", an error pattern appropriate for B1-B2. The same prompt's B option `"It's a very long trip."` is fully grammatical, which makes the C option the only "wrong" answer — but the test should have more than one clearly-wrong distractor.
- Impact: The placement test is the gateway to leveled content. If a primary-school student (ages 6-12) is asked to choose between "Yes, it was very funny." (A), "No, I doesn't like it." (B), and "Movies is too long for me." (C) for the A2 prompt "Did you enjoy the movie last night?" (line 116), the B and C options are so heavily broken that the test essentially becomes a "pick the obvious correct answer" exercise rather than a real placement instrument. The test also has a duplication issue: A2 question 5 (line 148) uses "I went to the zoo" as the A option, and A2 question 2 (line 117) about movies; the topic variety is reasonable, but the distractor quality is uneven. Most importantly, the file is an orphan in primary-advantage (see LR-primary-advantage-075-002), so a contributor who wires it in will inherit a placement test with primary-inappropriate distractor quality.
- Recommendation: In a separate authorized content-remediation track, replace broken distractors (especially line 184, 191, 269) with single-error distractors at the target CEFR level. Use a single-error distractor pattern: each B/C option should have exactly one identifiable error, at the level being tested. Validate every option for syntactic completeness before merging. Given that the file is also orphan in primary-advantage (LR-primary-advantage-075-002), the highest-leverage fix is to delete the file or archive it under `data/archived/` with a `README` noting it is an unrevised reading-advantage carryover. No source edit performed in this review-only track.
