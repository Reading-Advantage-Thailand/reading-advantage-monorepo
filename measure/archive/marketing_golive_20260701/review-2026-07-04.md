4. **Migration step assumes marketing tables** — migrate step runs all pending migrations using `DIRECT_DATABASE_URL`; the marketing schema is in migration `0021_sales_advantage.sql`, so the target DB must be ready.
5. **Authenticated smoke coverage missing** — the smoke script cannot verify campaign/video functionality without a session cookie, leaving core go-live behavior unverified by automation.
6. **Manual QA deferred** — end-to-end login → campaign → script → persist flow is the final gate and is not yet scheduled/recorded.
