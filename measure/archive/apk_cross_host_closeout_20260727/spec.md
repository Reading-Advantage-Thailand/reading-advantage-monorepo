# Specification: APK Residual Cross-Host Retirement and Closeout

## Objective

Close only cross-host residual work that no vertical cohort owns. It is not a big-bang host migration or substitute for per-game proof.

## Requirements

- Start only after the foundation crosswalk is accepted and every implementation/disposition cohort has an accepted or explicitly blocked outcome.
- Inventory residual shared host adapters, registries, routes, and retirement paths; reject any item owned by a vertical cohort.
- Reconcile cohort receipts without claiming an unproven game complete.
- Retire only residual shared infrastructure whose last caller is proven migrated or whose retained owner is explicit.

## Acceptance criteria

- The residual inventory is empty or has explicit retained owners.
- No cohort-owned title or retirement action is duplicated.
- Program-level closeout is withheld while the denominator reconciliation or any cohort gate remains unresolved.
