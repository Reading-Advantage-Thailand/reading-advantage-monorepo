`23bb5ad578c01fb29f9e8bb76a7d934d24a4b286` and historical implementation
evidence at reachable withdrawal parent
`1a21fb951e27bb4df8a5e8f7b1685cea9e6efb9f`. Text citations hash exact
inclusive LF-terminated line bytes obtained with `git show <revision>:<path>`.

Current catalog implementation, catalog prose, active test specification,
historical implementation, historical active design, and unknown are separate
classes. The empty `git ls-tree` result is bounded to the exact historical
cartridge candidate directory and is never promoted to repository-wide
absence. Historical source describes source code at that revision only; it
does not establish current, browser, physical-input, responsive, persistence,
or production behavior. No browser session was attempted because no current
gameplay route or implementation envelope was admitted.

Negative fixtures explicitly reject catalog-to-implementation,
historical-to-current, test-to-live, bounded-to-global, source-to-browser, and
design-to-runtime promotion. The package makes no ontology, implementation,
product-owner acceptance, accepted-manifest, or downstream decision.
