## 3. Code quality observations

- **Generators dominate the analysis.** `generate-corpus.mjs`, `generate-blueprints.mjs`, `generate-capabilities.mjs`, `generate-responsive.mjs`, and `generate-asset-usage.mjs` produce the artifacts. This is acceptable for scaffolding, but the current generators encode product conclusions (mechanics, roles, responsive strategies) rather than parsing source files.
- **Single-scene assumption.** `generate-corpus.mjs` assigns `sceneIds: [\`scene:${slug}:main\`]` to every game, then all downstream matrices key off that one scene. This contradicts the spec's requirement to enumerate concrete scenes/states per game.
- **Templated content.** `generate-blueprints.mjs` contains a 29-entry `mechanics` lookup with one-liner descriptions. `generate-responsive.mjs` uses a single fixture set for all 29 games. `generate-asset-usage.mjs` attaches the same 19 capabilities to every usage.
- **Tests pass but do not catch the defects.** The 23 vitest tests verify schema shape, referential integrity, and coverage counts. They do not verify that blueprints are derived from source code, that fixtures are game-specific, or that asset roles are scene-extracted.
- **Audit evidence is cohort-level.** `existing-asset-audit.md` groups findings by cohort rather than listing per-candidate dimensions, provenance, license, and disposition as required by FR7.

3. **Asset production and cartridge tracks are dependency-blocked.** The program plan says they may proceed only after this track's artifacts are accepted. Because this track is now reopened, those successor tracks should remain blocked until Phase 8 completes.
4. **Synthetic outputs could be mistaken for source evidence.** The passing test suite and generated JSON files look like completed analysis. Without the explicit Phase 8 remediation, the team risks building the shared kit and asset contracts on unproven assumptions.
5. **`build-graph audit` invocation failed silently.** `verification.md` notes it returned "no report or usable exit code." This is not a blocker for a requirements track but should be resolved before final acceptance.
