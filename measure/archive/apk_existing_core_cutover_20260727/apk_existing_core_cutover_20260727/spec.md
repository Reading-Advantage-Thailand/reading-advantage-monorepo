# Specification: Existing APK Core Cartridge Revalidation and Cutover

## Scope

Revalidate and, only after proof, cut over these already-built cartridges: Dragon Flight, Magic Defense, Dungeon Liberator, The Sorcerer's Ziggurat, and Astral Mage.

## Requirements

- Revalidate each cartridge against accepted mechanic evidence and current T11 public APIs; historical build completion is not current cutover proof.
- Before a title can claim host-proof completion or cutover, consume accepted Asset
  Contract v2 and a per-role suitability dossier that separates semantic intent,
  physical descriptor/animation behavior, and reuse/ingest/block decision.
- For every title, prove one pinned pack/binding and selected output in Advantage Games, Reading, and Primary, then retire exactly the replaced legacy paths after both host proofs.
- Preserve T10/T11 disclosures and stop on missing semantic adoption, host completion, tenant-safe persistence, or retirement evidence.
- Keep all work vertical and title-scoped; do not create a host-wide migration.

## Acceptance criteria

- Each of the five titles has independent deterministic, responsive, host, and retirement evidence.
- No app-local source asset copy or full-pack default delivery remains for an accepted cutover.
- No semantic state assumes a legacy sheet layout or frame count; presentation
  behavior is descriptor-driven and mechanically verified.
