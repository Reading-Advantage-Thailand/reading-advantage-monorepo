## Sample route.ts verification (5.3 / 5.4)

Five `route.ts` files were sampled from the 27, chosen to cover the largest and the most tenant-sensitive paths. The pattern is consistent across all five:

| # | File | Authorization pattern | `schoolId` predicate? |
|---|------|----------------------|----------------------|
| 1 | `app/api/classes/route.ts:38-76` (287 L) | `session.user.role !== 'TEACHER' && 'ADMIN'` gate; `tx.insert(scienceClasses).values({ ..., teacherId: session.user.id })` | No (uses `teacherId` ownership) |
| 2 | `app/api/classes/[classId]/route.ts:24-43` (221 L) | `getClassDetailWithCurriculum(classId)` then `teacherId === user.id` OR `isAdmin` OR `students.some(s => s.id === user.id)` (enrollment) | No (user-centric ownership) |
| 3 | `app/api/ai/update-mastery/route.ts:1-120` (624 L) | `getCurrentSession()` then arithmetic on `scienceStandardMastery` / `scienceAttempts` keyed by `studentId = session.user.id` | No |
| 4 | `app/api/ai/recommendations/route.ts:6-80` (400 L) | `getCurrentSession()` then `db.select().from(scienceLessons)` / `scienceAttempts` with no tenant predicate | No (relies on caller-supplied `attemptId`) |
| 5 | `app/api/students/[studentId]/lessons/[lessonId]/analytics/route.ts:30-100` (304 L) | `isAdmin` bypass; otherwise `EXISTS (SELECT 1 FROM scienceClasses WHERE teacherId = session.user.id AND EXISTS … studentId = ?)` | No (teacher-of-student relationship) |

The same user-centric model repeats in `app/api/lessons/[lessonSlug]/route.ts` (lines 88-104: `classRows.some(c => c.teacherId === userId)` + `scienceClassStudents.studentId = userId`) and `app/api/lessons/[lessonSlug]/quiz/route.ts` (lines 84-97: identical pattern).

**Conclusion for 5.3/5.4:** the science-advantage app does not use `schoolId` predicates because **the science schema has no `schoolId` columns** to predicate against. The architectural tenancy model is `users.schoolId → users` (where present on the row) and otherwise `scienceClasses.teacherId → users.id` plus `scienceClassStudents.studentId → users.id` membership. This is fundamentally different from `packages/api` (which uses `createTenantDB` with `tenant.schoolId`).
