## Summary roll-up

| Section | Pass | Fail | Deferred | Total |

| §12 Monorepo Hygiene | 3 | 4 | 0 | 7 |

The single biggest non-compliance cluster is **build/lint/types gating**: `pnpm turbo run check-types --filter=science-advantage` is a no-op (no `check-types` script in `package.json`), `next.config.ts` masks the ~370 type errors via `ignoreBuildErrors: true`, and `pnpm turbo run lint` returns exit 1. All three are pre-existing and known — already captured in `measure/tech-debt.md` row `auth_strategy_review` (2026-05-03) — so they are tracked; the new audit adds evidence and sharpens the work item rather than surfacing a fresh blocker.

The second cluster is **commit hygiene**: Conventional-Commits format compliance is excellent (50/50) but track-id linking is poor (7/50). Most of the 43/50 without a track ID are part of the `prisma_drizzle_science_controllers_20260505` migration that completed in 2026-05-23; the audit is recording the gap but the gap is not blocking new work.
