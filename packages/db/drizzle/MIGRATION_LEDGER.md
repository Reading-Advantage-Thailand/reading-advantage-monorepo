# Migration Ledger — Re-Stamp Design Note

## Background

The drizzle-orm migrator (v0.44.7, `pg-core/dialect.js:62`) uses a strict-< comparison
on the `when` timestamp to decide which journal entries have already been applied.
This means any entry whose `when` is less than or equal to the highest previously
applied `when` will be silently skipped — even if its `idx` is higher.

The production ledger accumulated entries with `when` stamps that are out of order
relative to their `idx`. Several entries from the 2025-era codecamp work (idx 3–8)
and later entries (idx 11, 13–15, 17, 18) have `when` values that predate the
production ceiling, causing the migrator to skip them on fresh databases.

## Production-Ledger Ceiling

The highest production `when` stamp before re-stamping is **1779120000000** (idx 16,
`0016_users_grade_level`).

All re-stamped entries must have `when` values that respect the strict-`<` ordering
relative to their position in the journal.

## Re-Stamp Strategy

The chosen interpolation stamps keep entries 0–16 at or below the production
ceiling while placing entries 17+ above it, preserving strict-`<` ordering by `idx`:

## Invariant

After re-stamping, the following invariant holds:

- **Entries 0–16**: all `when` ≤ 1779120000000
- **Entries 17+**: all `when` > 1779120000000

This ensures the strict-`<` migrator processes entries in `idx` order on both
existing production databases (where older stamps are already applied) and fresh
databases (where all entries must be applied sequentially).

## Hand-Written Migration Protocol

When writing migrations by hand (not generated by `drizzle-kit generate`), follow
this three-part protocol:

1. **SQL file**: Create `drizzle/NNNN_descriptive_name.sql` with the DDL statements.
2. **Journal entry**: Add a corresponding entry to `drizzle/meta/_journal.json` with
   the next sequential `idx`, a `when` stamp above all existing entries, and the
   matching `tag`.
3. **Integrity test**: Add or update tests in `src/__tests__/` to verify the
   migration applies cleanly and the journal remains consistent.
