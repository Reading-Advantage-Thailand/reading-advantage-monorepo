# @reading-advantage/srs-engine

Domain-neutral FSRS scheduling, review processing, queues, proficiency,
calibration, and session composition for every Advantage application.

The authoritative `kst-srs.v3.2` package, contract, parameters, fixture, and
migration compatibility set lives in
`packages/mastery-runtime-compat/runtime-manifest.json`. Add acceptance fixtures
before changing scheduling behavior, follow semver for public contracts, and
verify both the packed artifact and synthetic Codecamp consumer before release.
Consumers must pin an allowed exact version rather than `*` or `latest`.
