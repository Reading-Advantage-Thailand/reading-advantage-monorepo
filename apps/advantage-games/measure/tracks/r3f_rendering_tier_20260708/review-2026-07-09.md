## 1. Summary of changes

The track established React Three Fiber as a new 3D/2.5D rendering tier and rewrote The Abyssal Well as the exemplar:

- **Stack contract (S1):** documented Konva-vs-R3F decision policy in `measure/tech-stack.md`; added `three`, `@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing` as runtime deps and `@react-three/test-renderer`/`@types/three` as dev deps; created a minimal R3F smoke scene with Jest harness tests; fixed ESLint `react/no-unknown-property` scoping for R3F files and a `StartScreen` icon-type clash.
- **Abyssal Well rewrite (S2):** retyped the pure logic module from `VocabularyItem` to `SentenceItem`; deleted the Konva render layer; added `AbyssalWellScene.tsx` (R3F Canvas, perspective camera, tube geometry, enemy/projectile meshes, drei Text, bloom postprocessing); rewired `AbyssalWellGame.tsx` with rAF-driven logic ticks and dynamic loading; added scene-graph and component tests; produced a 25/25 compliance report with one documented R3F-canvas deviation; recorded 94.57% statement coverage / 73 tests.
- **Gameplay redesign (S5):** after S2 user verification found the original rules leaked the answer, the team added Story S5 on 2026-07-08. Implemented cycling words (all words spawn at once, no target highlight), breach wraps harmlessly with per-lap speedup, wrong hits cost a life, continuous angle rotation via hold input, and angular-proximity collision. Updated `abyssalWell.ts`, `abyssalWellConfig.ts`, `wellProjection.ts`, tests, and HUD/start-screen copy.
- **Workflow gate (S3):** added a "Rendering Stack" decision step to `.claude/skills/vocab-game-builder/SKILL.md` with R3F scaffolding guidance and recorded the "don't fake 3D in a 2D canvas" lesson.
- **Candidates (S4):** produced `r3f-game-candidates.md` and seeded the top candidates as stub entries in `measure/tracks.md`.
- **Asset pass (S6):** added Story S6 to retheme Abyssal Well with KayKit Dungeon Remastered assets; created `kaykit-asset-shopping-list.md`. No KayKit files have landed yet, so S6 is unstarted.

## 3. Code quality observations

- The pure-logic + thin-render-layer architecture is preserved: R3F only handles presentation and input; game state advances in `abyssalWell.ts`.
- Bundle isolation is respected: three.js is loaded only through `next/dynamic` on the abyssal-well route; build output shows it in one async chunk referenced only by abyssal-well pages.
- Test strategy is solid: red/green cycles for R3F harness, render layer, and S5 redesign; scene-graph assertions avoid GPU dependency.
- The S5 redesign was responsive to user feedback and kept the logic deterministic with injectable RNG.
- The S6 scope expansion is documented and isolated; it does not bleed into S2/S5 implementation.
