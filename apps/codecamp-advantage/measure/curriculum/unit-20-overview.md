# Unit 20: Advantage Play Kit Game Creation

Unit 20 is an append-only module after the existing Real-World Practice unit.
In-progress cohorts retain their original 19-unit sequence; newly assigned
cohorts receive `codecamp.unit.apk-game-creation@1.0.0`.

The three class periods use one graph-approved objective sequence:

1. I Do: trace the Phaser lifecycle and host/cartridge boundary.
2. We Do: complete a guided APK manifest with deterministic repository checks.
3. You Do: independently build and submit a sentence-sorting cartridge.

The authoritative activity, resource, repository, rubric, migration, and SRS
identities live in `@reading-advantage/codecamp-knowledge/apk-unit`. Curriculum
data and the Codecamp route consume that contract; they do not redefine it.
